Projects

These are my side projects where I poke at Linux and cloud-native stacks to see how they work. I have created several personal projects over time but these are my notable ones that helped me understand system design, kubernetes and linux.

kettle/

Go · OCI · runc · gRPC · ttrpc · overlayfs · May '25

A minimal container runtime engine designed to emulate a containerd-like architecture: create, run and delete containers, pull remote images and keep overlayfs snapshots.

browser-orchestrator/

Rust · Restate · axum · Jan '26

A Rust-based microservice orchestration system aided by Restate for spawning multiple browser sessions exposed through a single axum server.
